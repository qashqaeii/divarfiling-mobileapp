# نقش اجزای اکوسیستم فایلینگ دیوار

**نسخه:** 3.0 — میزکار اصلی موبایل

این سند مرز مسئولیت **سرور**، **ویندوز** و **اندروید** را مشخص می‌کند.  
اپ اندروید برای کاربر بدون ویندوز **میزکار روزانه اصلی** است؛ ویندوز اختیاری برای قدرت‌کارها باقی می‌ماند.

---

## نمای کلی

| جزء | نقش |
|-----|------|
| **Django** | منبع حقیقت، CRM، فایلینگ، تحلیل، AI، استخراج ابری، اعلان |
| **اندروید** | میزکار روزانه کامل: CRM، فایلینگ، نقشه، تحلیل، استخراج، تیم، AI |
| **وب** | فروشگاه/پرداخت، گزارش‌های خیلی حجیم، اکانت |
| **ویندوز** | اختیاری — استخراج محلی بسیار حجیم و Excel سنگین |

---

## ۱. سرور Django (مرکز سیستم)

- دیتابیس PostgreSQL — منبع حقیقت
- Workspace، CRM، Matching، Notifications (FCM)
- Ingest استخراج موبایل و ابری
- تحلیل بازار / نقشه / insights برای API موبایل
- فروشگاه و لایسنس (وب)

---

## ۲. نرم‌افزار ویندوز (اختیاری)

استخراج انبوه محلی، Excel حرفه‌ای، PDF سنگین. دیگر پیش‌نیاز نیست.

---

## ۳. اپ اندروید (میزکار اصلی موبایل)

| حوزه | محدوده |
|------|--------|
| CRM | مخاطب، معامله، ملک، امروز، تطبیق، قالب پیام، تقویم |
| فایلینگ | مشاهده، جستجو، export اشتراکی، insights، نقشه |
| استخراج | سبک روی گوشی + Job ابری روی سرور |
| اعلان | FCM + deep link |
| تیم / AI / آکادمی / پشتیبانی | از اپ (API یا Custom Tab امن به میزکار) |
| پرداخت | فقط وب (Custom Tab) |

---

## ۴. استخراج ترکیبی

1. **فوری روی گوشی** — سقف لایسنس (سبک) برای کارهای خیابانی  
2. **ابری روی سرور** — حجم بالاتر، زمان‌بندی بدون وابستگی به روشن بودن گوشی  

---

## ۵. پیام‌رسانی به کاربر

> اپ موبایل میزکار روزانه شماست. استخراج سبک روی گوشی و استخراج ابری روی سرور انجام می‌شود. پرداخت و برخی گزارش‌های خیلی حجیم از وب در دسترس است.

---

*نسخه ۳ جایگزین فلسفه «فقط همراه ویندوز» شد.*
